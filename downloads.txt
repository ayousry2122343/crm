==============================================================
  CRM — AI Setup Guide (Ollama — مجاني بالكامل)
==============================================================

الخطوات دي بتنزّل Ollama + الموديلات اللي محتاجها الـ CRM
وبتظبط الـ .env عشان الـ AI يشتغل من غير OpenAI أو Anthropic.

--------------------------------------------------------------
  المتطلبات
--------------------------------------------------------------

- Linux (Ubuntu 20.04+) أو macOS
- RAM: 8GB minimum (16GB recommended for llama3.1:8b)
- Disk: ~6GB free space for models
- الـ CRM stack شغال (docker-compose up)

==============================================================
  الخطوة 1: تنزيل Ollama
==============================================================

# Linux:
curl -fsSL https://ollama.com/install.sh | sh

# macOS:
# نزّله من https://ollama.com/download/mac

# Windows (WSL2):
# نزّله من https://ollama.com/download/windows

# تأكد إنه شغال:
ollama --version

==============================================================
  الخطوة 2: تشغيل Ollama Server
==============================================================

# لو مش شغال تلقائي:
ollama serve

# بيشتغل على http://localhost:11434
# تأكد إنه شغال:
curl http://localhost:11434/api/tags

==============================================================
  الخطوة 3: تنزيل الموديلات
==============================================================

# --- موديل المحادثة (لصياغة الإيميلات) ---

# الخيار A: llama3.1:8b (الافتراضي — إنجليزي ممتاز)
ollama pull llama3.1:8b
# الحجم: ~4.7GB | RAM: ~8GB

# الخيار B: qwen2.5:7b (أقوى في العربي — مُوصى به للـ CRM)
ollama pull qwen2.5:7b
# الحجم: ~4.4GB | RAM: ~8GB

# الخيار C: للأجهزة الضعيفة (4GB RAM)
ollama pull phi3:mini
# الحجم: ~2.3GB | RAM: ~4GB

# --- موديل الـ Embeddings (للبحث الذكي) ---
ollama pull nomic-embed-text
# الحجم: ~274MB | RAM: ~1GB

# --- تأكد إن الموديلات نزلت ---
ollama list

==============================================================
  الخطوة 4: اختبار الموديل
==============================================================

# اختبار سريع (chat):
curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "llama3.1:8b",
    "messages": [{"role": "user", "content": "Say hello in Arabic"}]
  }'

# اختبار embeddings:
curl http://localhost:11434/api/embeddings \
  -H "Content-Type: application/json" \
  -d '{"model": "nomic-embed-text", "prompt": "test embedding"}'

==============================================================
  الخطوة 5: ظبط الـ .env
==============================================================

# افتح ملف .env في root المشروع:
#   /path/to/crm/.env

# غيّر السطور دي:

AI_DEFAULT_PROVIDER=ollama
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3.1:8b
OLLAMA_EMBED_MODEL=nomic-embed-text

# لو اخترت qwen2.5 بدل llama3.1:
# OLLAMA_MODEL=qwen2.5:7b

# لو Ollama على سيرفر تاني (مش localhost):
# OLLAMA_BASE_URL=http://192.168.1.100:11434

# --- باقي الـ .env يفضل زي ما هو ---

==============================================================
  الخطوة 6: إعادة تشغيل الـ API
==============================================================

# لو Docker:
docker-compose restart api

# لو بتشغل manually:
cd apps/api && pnpm dev

# هتشوف في الـ logs:
#   [AIService] AI provider: ollama

==============================================================
  الخطوة 7: اختبار في الـ CRM
==============================================================

1. ادخل الـ Dashboard
2. افتح أي Person أو Deal
3. اضغط "Compose Email"
4. اضغط "Draft with AI" (صياغة بالذكاء الاصطناعي)
5. اكتب نيتك مثلاً: "متابعة عرض الأسعار"
6. اختار اللغة والأسلوب
7. اضغط "Generate" — هيرجع subject + body جاهزين

==============================================================
  ملاحظات إضافية
==============================================================

- Ollama بيشتغل على CPU بدون GPU — بس أبطأ
- لو عندك NVIDIA GPU: Ollama بيستخدمها تلقائي (CUDA)
- أول request بياخد وقت أطول (بيحمّل الموديل في الـ RAM)
- الطلبات بعد كده بتكون أسرع (الموديل cached)
- لو عايز تشغل Ollama في Docker:
    docker run -d -v ollama:/root/.ollama -p 11434:11434 ollama/ollama
    docker exec -it <container> ollama pull llama3.1:8b

- لو السيرفر production ومحتاج أداء عالي:
    استخدم GPU server (AWS g5.xlarge أو Hetzner GPU)
    أو استخدم OpenAI/Anthropic API مع:
      AI_DEFAULT_PROVIDER=openai
      OPENAI_API_KEY=sk-...
