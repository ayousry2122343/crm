## What Originally Needed External APIs (4 tasks) + Free Alternatives

### 1. AI/LLM Provider (T5.4 + T5.5)
   Original: OpenAI API ($) or Anthropic API ($)
   Alternative: Ollama (FREE, self-hosted)
   - Install: curl -fsSL https://ollama.com/install.sh | sh
   - Models: llama3.1:8b (chat), qwen2.5 (Arabic-strong)
   - API: OpenAI-compatible (http://localhost:11434/v1)
   - Code: Same OpenAI SDK, just change baseURL

### 2. Embeddings API (T5.7)
   Original: OpenAI embeddings ($0.0001/1K tokens)
   Alternative: Ollama embeddings (FREE)
   - Model: nomic-embed-text (274MB) or all-minilm
   - Same endpoint: POST /api/embeddings

### 3. reCAPTCHA (T4.3 - partial)
   Original: Google reCAPTCHA (free but requires Google account + domain)
   Alternative: Three-layer local protection:
   - Honeypot field (hidden CSS input, bots fill it)
   - Rate limit per IP (5 submissions/hour)
   - Math CAPTCHA in Arabic ("كم = ٧ + ٣؟")

### 4. Production Email SMTP (T4.1 - production only)
   Dev: MailHog (already configured)
   Free production options:
   - Brevo (ex-Sendinblue): 300 emails/day free
   - Resend.com: 3000 emails/month free
   - Gmail SMTP: 500/day with App Password
   - Postal (self-hosted): unlimited, needs VPS
